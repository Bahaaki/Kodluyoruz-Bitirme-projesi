# 🎮 Game Listing Web Application

A responsive game discovery and listing web application built with **React.js**, developed as the graduation project for the **<Code16> Front-End Web Development Bootcamp** organized by **Kodluyoruz Academy & Bursa Metropolitan Municipality**.

---

### ✨ Features
- 🔍 Browse and discover popular video games with responsive UI.
- 📱 Fully responsive layout across mobile, tablet, and desktop screens.
- ⚡ Component-based architecture leveraging React Hooks and modern state management.

---

### 🛠️ Built With
- **Frontend:** React.js, JavaScript (ES6+)
- **Styling:** CSS3 / Modern Flexbox & Grid
- **Tools:** Git, GitHub, npm
